# Rustamp 1.0.0

Rustamp is a Windows music player with a classic skin interface. This release
fixes playlist resizing so the skin fills the resized window, and scales a
smaller playlist with the player when switching to double size.

The portable archive includes the player, its helper programs, plug-in host,
and third-party notices. A SHA-256 checksum accompanies the archive. The build
is unsigned; Windows may show a SmartScreen warning. There is no installer or
automatic updater.

Known limitations include incomplete native MilkDrop support, unverified GPU
and data delivery for the classic MilkDrop plug-in, and unfinished areas of
Preferences and crossfade. Clean Windows installations and real audio hardware
have not been verified for this release. See the README Status section for
details.
