## Lessons that were paid for

- **A gate must branch on the exit code, not print it.** Printing an exit code is
  not a gate. A red clippy was merged twice this way; one merge had to be reverted.
- **A lane that died mid-work is not a lane.** Its card can describe a state its
  files never reached. Finish the work in a fresh lane.
- **Never build a package or trust a gate in a tree whose status you have not just
  read.** A lane wrote nine files into the canonical tree; the packages built there
  may have compiled them, so their bytes are not guaranteed to be `main`'s.
- **OpenCode subagents inherit the orchestrator's working directory.** A relative
  path writes into `D:\code\Rustamp`. Create the worktree before the prompt and
  name exactly one path.
- **The suite measures geometry; the owner sees appearance.** Every defect of the
  last two days came from that gap. A further automated test is not the answer - a
  visual check by the owner is.
- **Readiness documents are snapshots.** Six of their lines have been stale or
  wrong; one lane checked a line expecting it stale and found it accurate. Verify
  with file, line and commit - in both directions.
- **State predictions so they can be refuted.** One was stated, checked and found
  wrong, and the runtime (0.15 s to 30 s) identified a timeout in one step.
