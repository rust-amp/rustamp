# Task card E4b — EBU R128 tag production (metadata half)

**Scope**: `crates/rustamp-meta/**`, this card.

## 1. Goal

The ReplayGain half of the tag layer (card E4) could *carry* the
`R128_TRACK_GAIN` / `R128_ALBUM_GAIN` keys but had no way to *produce* them.
This card measures the loudness the way ITU-R BS.1770-4 measures it, turns
the measurement into the values the tags hold, and writes and reads those
values where the format can carry them.

The ReplayGain values themselves are **not** touched: they keep their own
measurement (the ReplayGain 1.0 filter, a mono downmix, the 95th
percentile of 50 ms blocks) and their own tags.

## 2. The measurement

`crates/rustamp-meta/src/r128.rs` (new) holds the measurement:

* **K-weighting** — two biquadratic stages: the high-shelf "pre-filter"
  (f0 = 1681.974450955533 Hz, G = 3.999843853973347 dB,
  Q = 0.7071752369554192) and the RLB high-pass (f0 = 38.13547087602444 Hz,
  Q = 0.5003270373238773).
* **Coefficient source** — BS.1770-4 publishes the coefficients of both
  stages for 48 kHz (its tables 1 and 2). For every other rate the
  filters are *recomputed* from the same design (the analog prototype with
  the standard's parameters, bilinear transform, prewarped at the sample
  rate) — never resampled from the 48 kHz version. The test
  `the_48_khz_coefficients_match_the_standard` pins the computed
  coefficients against the published tables (agreement to 1e-12).
* **Per channel** — every channel is K-weighted on its own; there is no
  mono downmix. The channels are summed with the weights of the standard:
  1.0 for left, right and center, 1.41 for the surrounds, 0 for the low
  frequency effects channel. The channel order is the default of
  WAVE_FORMAT_EXTENSIBLE (mono, stereo, 3D1, 3D2, 5D1).
* **Blocks** — 400 ms with 75 % overlap (a 100 ms step). A block that is
  cut short by the end of the signal is kept when it holds at least a
  quarter of a full block.
* **Gating order** —
  1. the *absolute* gate: every block below −70 LUFS is dropped;
  2. the *relative* gate: 10 LU below the mean of the block loudness
     values that passed the absolute gate;
  3. the integrated loudness is the loudness of the mean energy of the
     blocks that passed both gates.

The album is measured the way the standard measures a programme: the
blocks of all its tracks are **pooled and gated together**, not track by
track (`r128_album_gain_q8`, `AlbumValues::r128_album_gain_q8`).

## 3. The values

```
R128_TRACK_GAIN = (-23 LUFS - integrated_lufs) as Q7.8
R128_ALBUM_GAIN = (-23 LUFS - pooled_lufs)     as Q7.8
```

A track below the absolute gate has no measurable loudness; its gain is
then the neutral 0, the same convention the ReplayGain values use for
silence.

## 4. What was built

- `src/r128.rs` (new): `LoudnessBlocks` (the blocks of a signal, measured
  per channel), `r128_track_gain_q8`, `r128_album_gain_q8`,
  `R128_TARGET_LUFS`.
- `src/dsp.rs` (new, private): the biquad both measurements use.
- `src/replaygain.rs`: `analyze_replaygain` measures the BS.1770 blocks
  next to the ReplayGain values and hands them over in
  `ReplayGainAnalysis::loudness_blocks`. The ReplayGain values, the
  histograms and the tags are unchanged.
- `src/album.rs`: `AlbumValues::r128_album_gain_q8` — the pooled value.
- `src/write.rs` / `src/read.rs`: the R128 keys are written and read as
  ID3v2 `TXXX` frames (see below); the Vorbis family carries them as
  plain comments.
- `src/lib.rs`: the module and the re-exports.

## 5. Which containers carry the tags

| Container | Tag | R128 keys |
|---|---|---|
| FLAC, Ogg Vorbis, Opus, Speex | Vorbis comments | read + write (plain comments) |
| MP3, AAC, WAV, AIFF | ID3v2 | read + write (`TXXX` frames, description = the key) |
| M4A, MP4 | ilst | refused, reported |
| APE, MPC, WavPack | APEv2 | refused, reported |

`lofty` 0.25.4 has no `ItemKey` for the R128 keys in ID3v2, so the writer
adds them to the concrete ID3v2 tag and hands the tag back to the generic
model, which keeps such a frame next to the frames it models itself; the
reader looks for them in the concrete tag of the file.

## 6. Tests

Headless, no audio hardware, no window:

- `the_48_khz_coefficients_match_the_standard`: the computed coefficients
  against the published tables;
- `the_measured_loudness_matches_the_standard`: the published test signal
  of the standard (a 1 kHz sine with an RMS of −23 dBFS measures
  −23 LUFS), and the agreement with an *independent* implementation of the
  standard that uses the published coefficients and works in `f32` — the
  two must agree within ±0.1 LU;
- `a_stereo_signal_is_measured_over_its_channels`: two uncorrelated tones
  measure −20 LUFS, 3 dB above one of them, and 6 dB above the mono
  downmix of the same signal;
- `the_stereo_value_is_three_decibels_better_than_the_old_one`: the value
  the old (ReplayGain-derived) approach produced for the same stereo
  signal, and the 3 dB it was off;
- `the_gates_drop_the_silence`, `a_silent_signal_has_no_loudness`,
  `the_r128_gain_brings_the_track_to_the_target`,
  `the_album_gates_the_blocks_of_all_tracks_together`,
  `the_channel_weights_follow_the_standard`;
- integration: the R128 keys round-trip on FLAC, Ogg, MP3, AAC, WAV and
  AIFF, reach an MP3 as `TXXX` frames and a WAV as an ID3v2 chunk, keep
  the unknown frames of the tag, do not disturb the ReplayGain tags, and
  are refused (and reported) on MP4.
